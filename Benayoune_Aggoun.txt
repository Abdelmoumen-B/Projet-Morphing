4 - Calcul et génération des images intermédiaires


1. Une fois les couples de points sauvegardés dans le fichier "points.txt", on a commencé par écrire une fonction permettant de relire ce fichier et de stocker les couples de points dans une structure de données adaptée.

2. On a défini une structure "Couple" contenant un point dans l’image de départ et un point dans l’image d’arrivée, ainsi qu’une structure "Triangle" contenant trois indices de points.

3. On a écrit une fonction permettant de calculer les points intermédiaires pour un paramètre alpha donné, en utilisant la formule :
   P_inter = (1 - alpha) * P_depart + alpha * P_arrivee

4. Pour pouvoir déformer l’image proprement, on a mis en place une triangulation des points intermédiaires. On commence par découper le rectangle de l’image en deux triangles, puis on ajoute progressivement les autres points en découpant les triangles existants.

5. On a écrit des fonctions mathématiques de base :
   - calcul de déterminant
   - test pour savoir si un point est dans un triangle
   - calcul des coordonnées barycentriques d’un point dans un triangle

6. Pour chaque pixel de l’image intermédiaire, on cherche dans quel triangle il se trouve, puis on calcule ses coordonnées barycentriques dans ce triangle.

7. Grâce à ces coordonnées barycentriques, on projette le pixel dans le triangle correspondant de l’image de départ et dans celui de l’image d’arrivée.

8. On récupère alors la couleur dans l’image de départ et dans l’image d’arrivée, puis on interpole les couleurs avec le même paramètre alpha.

9. On obtient ainsi une image intermédiaire complète correspondant à une valeur donnée de alpha.

10. On répète ce processus pour k variant de 0 à N, avec alpha = k / N, ce qui permet de générer N+1 images intermédiaires.

11. Chaque image générée est sauvegardée au format PPM dans le dossier "Images_Intermediaires" sous la forme img_000.ppm, img_001.ppm, etc.


_______________________________________________________
5 - Génération du film final


1. Le programme final est maintenant une commande de la forme :
   morphing image_depart.ppm image_arrivee.ppm N

2. Le programme commence par charger les deux images passées en paramètres.

3. Il permet ensuite à l’utilisateur de sélectionner interactivement les couples de points et de les sauvegarder dans le fichier "points.txt".

4. Une fois les points définis, le programme génère automatiquement les N+1 images intermédiaires dans le dossier "Images_Intermediaires".

5. Pour transformer ces images en une vidéo, on utilise un appel système à l’outil ffmpeg directement depuis le programme.

6. La commande utilisée est :
   ffmpeg -framerate 3 -i Images_Intermediaires/img_%03d.ppm -c:v libx264 -pix_fmt yuv420p morphing.mp4

7. Cette commande permet de créer une vidéo d’environ 10 secondes à partir des 30 images générées.

8. Le programme produit ainsi automatiquement le fichier final "morphing.mp4" qui montre la transformation progressive de l’image de départ vers l’image d’arrivée.

9. L’ensemble du processus, depuis la sélection des points jusqu’à la génération du film, est maintenant entièrement automatisé par une seule commande.
