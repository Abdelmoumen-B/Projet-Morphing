# Image Morphing en C

Projet universitaire réalisé dans le cadre de la Licence Informatique.

## Description

Ce projet implémente un algorithme de morphing d'images en langage C. L'objectif est de générer une transition progressive entre deux images à partir de points de correspondance définis par l'utilisateur.

Le programme permet :

* la sélection de couples de points entre deux images ;
* la génération de points intermédiaires ;
* la triangulation des points ;
* le calcul des coordonnées barycentriques ;
* la déformation progressive des images ;
* l'interpolation des couleurs ;
* la génération automatique d'une vidéo finale de morphing.

## Technologies utilisées

* Langage C
* Makefile
* ImageMagick
* FFmpeg

## Concepts informatiques mobilisés

* Structures de données
* Allocation dynamique
* Traitement d'images
